# 第 02 节 · 动手：vibe 一个小游戏

> 目标：在 10 分钟内，用 AI 从零 vibe 出一个能玩的小游戏。
> 别怕，跟着做，你只需要"说话"。

## 一、选一个游戏

新手建议从简单的开始，先体验完整流程：

| 游戏 | 难度 | 适合 |
|------|------|------|
| 猜数字 | ★ | 第一次 vibe，10 分钟搞定 |
| 21 点 / 石头剪刀布 | ★ | 想练逻辑分支 |
| 贪吃蛇（终端版） | ★★ | 想要一点实时交互 |
| 2048（终端版） | ★★ | 想练二维数组操作 |

本节以**猜数字**为例走一遍完整流程，参考实现见 `lab/demo_01_guess_game.py`。

## 二、第一句需求

打开你的 AI 编程工具（CodeBuddy / 你自己的 Agent 都行），说：

```
帮我用 Python 写一个命令行猜数字游戏：
- 程序随机生成 1 到 100 的整数
- 玩家输入猜测，程序提示"太大了 / 太小了 / 猜对了"
- 最多 7 次机会，用完没猜中就算输
- 只用 Python 标准库
```

AI 会给你一份能直接跑的代码。**先运行它**：

```bash
python demo_01_guess_game.py
```

## 三、迭代：让它更好玩

跑通之后，你一定会冒出新想法。一次提一个，让它改：

```
1. "在结尾显示我一共猜了几次"
2. "如果输入的不是数字，给个友好提示，别直接崩溃"
3. "猜对时，根据次数给个评价：3 次内=神，7 次=险胜"
4. "加一个再玩一局的选项"
```

每改一次，**立刻运行验证**。这就是 VibeCoding 的核心循环：

```
说需求 → AI 改 → 你跑 → 不满意 → 再说需求 → ……
```

## 四、参考实现

`lab/demo_01_guess_game.py` 是一个"vibe 完"的版本，包含了上面所有迭代点。
你可以：

- 直接运行它，感受成品
- 或者无视它，从空文件自己 vibe 一遍（更推荐！）

> 提示：自己 vibe 出来的，哪怕和参考实现不一样，也比抄来的更有价值。

## 五、卡住了怎么办

| 症状 | 怎么跟 AI 说 |
|------|------------|
| 报错 | 把**完整报错信息**贴给它："运行报这个错，帮我修：……" |
| 行为不对 | 描述**期望 vs 实际**："我猜对了它却说我输了，应该……" |
| 想加功能但不会描述 | 举例子："类似 xxx 那样的效果" |
| 代码看不懂 | 直接问："这段 while 循环是干嘛的，逐行讲讲" |
