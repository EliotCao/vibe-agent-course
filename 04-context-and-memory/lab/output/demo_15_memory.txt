============================================================
【演示二：Memory 召回结果注入到当前对话的 system】
============================================================

用户问: 帮我安排周末两天的活动。

召回的相关长期事实：
  [0.336] 用户每天预算 500 元。
  [0.335] 用户上次反馈：博物馆类景点很喜欢。
  [0.221] 用户对花粉过敏，户外活动需要避开花期。

=== 注入后的 system prompt ===
你是用户的助手。下面是用户的长期偏好和约束，请在回答中遵守：
- 用户每天预算 500 元。
- 用户上次反馈：博物馆类景点很喜欢。
- 用户对花粉过敏，户外活动需要避开花期。

=== Agent 回答 ===
好的，根据您的偏好和约束条件（预算每天500元、喜欢博物馆、花粉过敏需避开户外花丛），我为您策划了一个以“人文历史与室内探索”为主题的周末两天行程。

本行程设定为您所在城市或周边的通用安排，您可以根据实际地点选择具体的场馆。

### 💰 预算概览（两天总计）
*   **总预算：** 1000 元（500元/天）
*   **餐饮：** 约 400 元（午餐+晚餐，人均适中）
*   **交通：** 约 100 元（建议地铁/公交/打车）
*   **门票/活动：** 约 200-300 元（很多博物馆免费，特展收费）
*   **预留/杂项：** 约 200 元

---

### 📅 周六：历史沉淀与城市漫步

**上午：核心博物馆深度游**
*   **活动：** 前往您所在城市的**省级/市级博物馆**（如：省博物馆、历史博物馆）。
*   **理由：** 您上次反馈很喜欢博物馆，这是了解一个地区历史最好的方式，且完全室内，避开花粉。
*   **预算：** 门票通常免费（需提前预约）或特展门票约 50-80 元。
*   **注意：** 建议提前在官方公众号预约，避开周一闭馆日。

**中午：博物馆周边简餐**
*   **餐饮：** 在博物馆附近的商场或特色面馆用餐。
*   **预算：** 约 60 元。

**下午：文化艺术街区（室内为主）**
*   **活动：** 前往当地的**美术馆**或**非遗文化体验馆**。
*   **理由：** 相比户外公园，艺术街区通常有更多室内展厅，且充满文化气息。如果去非遗馆，可以体验手工制作（如陶艺、剪纸），非常杀时间且有成就感。
*   **预算：** 门票免费或体验课约 100 元。

**晚上：地道特色晚餐**
*   **餐饮：** 选择一家评分较高的本地特色菜馆。
*   **预算：** 约 150 元。

---

### 📅 周日：科技探索与休闲放松

**上午：科技馆或专题博物馆**
*   **活动：** 游览**科技馆**或**行业专题博物馆**（如茶叶博物馆、丝绸博物馆、铁路博物馆等）。
*   **理由：** 科技馆互动性强，非常有趣；专题博物馆通常有小而美的园林，但因为是庭院式布局，**只要不靠近花坛密集区域，过敏风险较低**。
*   **预算：** 门票约 30-60 元。

**中午：轻食/咖啡简餐**
*   **餐饮：** 在文创园区内找一家环境好的咖啡馆或轻食店。
*   **预算：** 约 80 元。

**下午：书店或室内商业展**
*   **活动：** 逛一家**大型特色书店**，或者看一场**室内商业展览**（如插画展、怀旧展）。
*   **理由：** 彻底避开户外花粉源，享受安静的阅读或观展时光，适合周末收心。
*   **预算：** 购书或门票约 100 元。

**晚上：满足的一餐**
*   **餐饮：** 火锅或人气餐厅。
*   **预算：** 约 120 元。

---

### 🚫 安全提示（针对花粉过敏）
1.  **避雷：** 虽然本行程以室内为主，但连接各景点的路途中请**佩戴口罩**，防止行道树（如梧桐、杨柳）花粉吸入。
2.  **备药：** 随身携带抗过敏药物。
3.  **景点选择：** 即使是户外的“古镇”或“街区”，请尽量避开有大片花卉景观的区域，优先选择石板路、建筑类景观。

您觉得这个安排如何？如果您告诉我您所在的具体城市，我可以为您推荐具体的博物馆名称和路线。

👀 观察回答里有没有体现：预算 500、避花粉、博物馆偏好。


============================================================
🎯 关键认识
============================================================
  1. Memory 不是 messages 列表，是一个'按语义可搜索'的事实库
  2. 检索 = 把 query embed → 跟所有记忆做余弦相似度 → top-k
  3. 用法：每轮对话开始前用当前 question 去 Memory 召回相关事实
           塞到 system prompt 里 → 模型自动'有了记忆'

  生产环境优化：
    - 向量库：换成 pgvector / qdrant，量大时 numpy 算余弦会慢
    - 缓存 embedding：相同文本不要 embed 两次
    - 阈值过滤：相似度低于 0.6 的不召回，避免污染 prompt
