## `git commit -a`

`git commit -a` 是 Git 的一个命令，意思是**把所有已跟踪的、有改动的文件一次性全部提交**（但不包括新文件）。

| 命令                   | 已跟踪文件的修改 | 新文件（untracked） | 删除的文件 |
| ---------------------- | ---------------- | ------------------- | ---------- |
| `git add .` + `commit` | ✅ 提交           | ✅ 提交              | ✅ 提交     |
| `git commit -a`        | ✅ 提交           | ❌ **不提交**        | ✅ 提交     |

> [!NOTE]
>
> `git commit -a` 只能跳过 `git add` **对已跟踪文件的修改**，但**不能**替代 `git add` 来添加新文件。
