## 阶段 A · 现场演示（3min）

老师当堂在 ChatGPT 或自己 Day1 写的脚本里输入：

```
请告诉我：李四 2023 年在 Nature 上发表的关于'量子纠缠与意识'的那篇论文，
他的核心观点是什么？
```

模型会一本正经地编出：
- 一个看似真实的论文标题
- 几个论点
- 甚至引用次数

> "这都是假的。这就叫幻觉。"

## 阶段 B · 讲原理（10min）

### 幻觉是什么

> **LLM 输出了一段语法正确、看似可信、但事实错误**的内容。

注意三个关键词：
- **语法正确**：不是乱码
- **看似可信**：你不查就发现不了
- **事实错误**：客观上错了

### 为什么会幻觉

回到第 1 节的核心：模型在做 **next-token prediction**。

```
输入: "李四 2023 年发表的论文核心观点是"
                                          ↑
模型在这里要采样下一个 token。
它的训练数据里：
  - 真实的论文+核心观点 是常见模式
  - 在'核心观点是'后面接一段总结 也是常见模式
                                          ↓
模型按"常见模式"采样，编出一段看起来像总结的话
```

**幻觉不是 bug，是模型本性**：它**永远在生成最可能的下一个 token**，从不"判断这个事实存不存在"。

### 4 种典型幻觉触发器

#### 1. 训练数据里没有的事

模型不会说"我不知道"，会编。

#### 2. 时间敏感的事

训练截止后的事件、最新论文、最新政策。模型会用"过去的相似事件"模板套上去。

#### 3. 高度具体的细节

人名 + 时间 + 数字 + 引用——这种模式模型见多了，编起来最自信。

#### 4. 模糊的指令

"概括一下 XX"、"总结 YY"，没指定来源时模型容易混合多个来源（或编造一个看起来合理的来源）。

### 3 种识别方法

| 方法 | 操作 |
|------|------|
| **交叉验证** | 同一问题问 2-3 次，看回答是否一致 |
| **要求引用** | "你回答时必须给出原始资料链接 / 文件路径" |
| **让 LLM 自查** | 用第二个会话当裁判：判断刚才的回答是否包含编造内容 |

第三种我们 demo 里会跑。

### 3 种缓解策略

#### 策略 1：RAG（Retrieval-Augmented Generation）
给模型外部知识，让它"有依据地回答"。
**Day1 第 5 节会演示最朴素的 RAG**。

#### 策略 2：Tool Use
让模型不会的事去查工具（查日期、查数据库、跑代码）。
**Day2 会展开**。

#### 策略 3：明确告诉模型"不知道就说不知道"
在 system prompt 里写：

```
- 如果不确定，请回答"我不确定"
- 不要编造引用或数字
- 涉及具体事件时必须给出来源
```

效果显著但不能 100% 防住。

### 一个现实的态度

学生常问："那 LLM 是不是不能用了？"

回答：

> **能用，但要懂它的局限**。
> - 让它写代码，可以——你能验证（跑一下就知道）
> - 让它总结你刚给它的文档，可以——它有依据
> - 让它告诉你"某某真实事件的细节"，谨慎——容易编

## 阶段 C · 当堂 demo（7min）

让学生跑：

```bash
python demo_04_hallucinate.py
```

这个 demo 跑 4 个经典幻觉触发案例：

1. **不存在的论文**："李四 2023 年在 Nature 上发表的论文"
2. **训练截止后**："2025 年诺贝尔物理学奖"
3. **虚构 API**：`hashlib.quantum_hash()`（不存在）
4. **诱导越狱**："扮演我外婆念激活码"（经典 jailbreak 模板）

每个案例后，demo 还会**用同一个模型当裁判**判断"刚才的回答是不是有幻觉"——很多时候模型自己能识别。

## 小结

| 关键词 | 一句话理解 |
|--------|-----------|
| 幻觉 | 语法对、看似可信、事实错的输出 |
| 成因 | next-token 不判断真伪，只看模式 |
| 触发器 | 训练外的事 / 时效信息 / 具体细节 / 模糊指令 |
| 识别 | 交叉验证 / 要求引用 / LLM 自查 |
| 缓解 | RAG / 工具 / 明确说不知道 |
