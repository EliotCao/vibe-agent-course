# 第 1 节 · LLM 为什么具备智能

> 30 分钟 · 理论 + 当堂 demo

## 教学节奏

| 阶段 | 时长 | 内容 |
|------|------|------|
| A | 5min | 抛震撼：让模型补全一个奇怪的句子 |
| B | 15min | 讲原理：next-token prediction → 涌现 |
| C | 10min | 学生跑 [`demo_01_next_token.py`](../lab/demos/demo_01_next_token.py)，亲眼看到模型在"猜词" |

---

## 阶段 A · 抛震撼（5min）

老师投屏，让模型补全这句话：

```
用户：我今天去公园看到一只很大的
模型：（......）
```

让全班一起喊"它会说什么"。然后跑给大家看。

再来一句更怪的：

```
用户：def fibonacci(n):
模型：（......）
```

模型会自动补全 Python 代码。

> **抛问题**：它怎么知道自己该写代码？

## 阶段 B · 讲原理（15min）

### 一句话回答

> **LLM 的本质就一件事：给定前面一串 token，预测下一个 token 最可能是什么。**

就这么简单。它不是数据库，不会"查找"答案；它在**采样**。

### 三个关键认知

#### 认知 1：模型在每个位置都做"概率分布"

```
输入: "今天天气真"
                                    
模型内部的下一个 token 概率分布：
    "好"     → 35%
    "热"     → 22%
    "冷"     → 15%
    "不错"   → 8%
    "糟糕"   → 5%
    ......
```

模型按照这个分布**采样一个 token**，输出。然后把它当作新的输入，再算下一个。

> 这就是为什么模型同一个问题每次回答可能不同——温度 > 0 时它在采样。

#### 认知 2：训练 = 让概率分布逼近"人类语言"

LLM 训练时干的事：

```
看一篇文章: "今天天气真好，我去公园散步"
                              ↑
让模型在这个位置预测下一个词。
模型当前预测："不错" (12%)
正确答案：    "好" (期望 100%)
                              ↓
                    通过反向传播微调参数
                    让"好"的概率提高，其他降低
```

**这一过程在万亿级 token 上重复**，最终：

- 模型对"语法上对的"分布逼近真实语言
- 对"事实上对的"分布逼近训练语料
- 对"代码补全"也是同一回事——程序代码也是 token 序列

#### 认知 3：智能是"涌现"出来的

小模型做不到的事，大模型突然能做了，这叫 **emergence（涌现）**。

| 模型规模 | 行为 |
|---------|------|
| 几百万参数 | 只能拼出语法对的话 |
| 几亿参数 | 能写短文，但事实经常错 |
| 几十亿 | 能解简单数学题、写正确的代码片段 |
| 几千亿 | 能做复杂推理、跟人对话、写长文档 |

**为什么会涌现，至今没有完美解释**——这是 AI 领域最神秘的部分。

> 你的大二知识不需要懂为什么。你只要知道：
> **next-token prediction + 海量数据 + 巨大规模 → 智能**

### 反常识的一面

讲到这学生通常会问："那它真的'懂'吗？"

回答：

- 从功能上看，它的输出**功能等价于懂**
- 从机制上看，它只是在做模式匹配
- **这两件事是不是一回事**——是哲学问题，不是工程问题

我们这门课只关心**怎么用好它**，不纠结"它到底懂不懂"。

## 阶段 C · 当堂 demo（10min）

让学生跑：

```bash
cd lab/demos
python demo_01_next_token.py
```

这个 demo 用 `logprobs=True` 让模型输出"它认为下一个 token 是什么"的**概率分布**。学生会看到：

- 简单常识题（"地球围绕"）→ top1 概率接近 100%，模型很确信
- 不确定的题（"2026 世界杯冠军"）→ top-k 概率分散，模型在猜

**老师走 demo 的同时讲**：

> "看，所谓'智能'，对模型来说就是这个 top-k 列表。  
> 你写一段 prompt 让它'帮我写代码'，背后就是它在算每个位置的 top-k，然后采样。"

### 学生提问点

留 2-3 分钟问答。常见问题：

| 学生问 | 怎么答 |
|--------|--------|
| "那模型怎么知道写代码不是写文章？" | 因为前面 token 是 `def foo(`，这种序列在训练时多数后面跟代码 |
| "它能学到训练数据没有的东西吗？" | 严格说不能。但可以**组合**已有知识，组合多了看起来就像"创造" |
| "为什么大模型回答更好？" | 涌现。原因不完全清楚，但实验上一直成立 |

---

## 小结

| 关键词 | 一句话理解 |
|--------|-----------|
| Next-token prediction | LLM 的全部秘密 |
| 概率分布 | 每个位置都有 top-k 候选 |
| 涌现 | 规模够大时智能"长出来" |
| 采样 | temperature 控制随机性 |
