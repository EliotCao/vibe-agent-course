🎯 v2 Agent 跟 第 4 章 朴素版的区别
============================================================
  ① ContextManager：messages 超过阈值时主动压缩（截断/摘要/分层）
  ② Memory 召回：每轮用 user_input 检索相关长期事实，注入到 system
  ③ Memory 提炼：对话结束时用 LLM 提炼新事实，写回 Memory

  这三件事加在一起，让你的 Agent 第一次有了'跨会话的记忆'。
  下一步（第 6/7 章）要做的：把这些组件接进真实的 Coding Agent。
