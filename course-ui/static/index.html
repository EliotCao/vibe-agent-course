👋 欢迎来到 Vibe Agent 课程

本工具把 01 ~ 08 节课的 Markdown 讲义渲染成更易读的页面，并且让每节课的 Python Demo 可以 一键运行，输出实时回流到浏览器。

  • 📚 左侧选择课程 → 阅读章节讲义
  • 🐍 切到 “代码示例” 选项卡 → 点击 ▶ 运行 demo
  • ⌨️ 交互式 demo 可在终端面板里输入文字并回车

提示：运行示例前请先在仓库根目录配置好 .env（参考 .env.example），否则 LLM demo 会因缺少 API Key 报错。
