## 方向一：继续优化你的 Coding Agent（个人）

在第 1-7 章搭建的 Coding Agent 基础上，**至少添加 2 个特色功能**，让它在某个场景下明显比"裸版"更好用。

### 可行方向参考

| 方向 | 难度 | 说明 |
|------|------|------|
| 并行工具调用 | ★★ | 一次 LLM 回复里多个 tool_calls 并发执行，显著加速 |
| 流式输出 + 进度条 | ★ | 回答逐字输出，工具调用阶段显示 spinner |
| 代码索引（tree-sitter） | ★★★ | 解析项目文件的函数/类定义，让 Agent 定位更精准 |
| 多文件 diff 预览 | ★★ | edit 前先显示 diff，用户确认再执行 |
| 会话持久化 | ★ | 退出后再启动能恢复上次对话和上下文 |
| 自动 commit | ★ | 修改完代码自动 `git add + commit`，message 由 LLM 生成 |
| Web UI | ★★ | 用 Gradio / Streamlit 替代 CLI，支持文件树 + 对话 |
| 自我改进循环 | ★★★ | 跑完任务后自动 review 自己的工具调用记录，提出优化建议 |
| 多 Agent 协作 | ★★★ | Planner + Coder + Reviewer 分工，流水线执行 |
| 沙箱隔离 | ★★ | bash 在独立 Docker 容器里执行，主进程只收结果 |
| 智能上下文裁剪 | ★★ | 根据当前任务自动判断哪些历史对话可以压缩/丢弃 |
| MCP 协议支持 | ★★ | 让你的 Agent 能调用 MCP Server 提供的工具 |

### 验收标准

1. 代码推到 `final-project` 分支，README 里写清新增了什么功能
2. 同一个任务，裸版 vs 加强版，截图/录屏证明改进效果
3. NPC 仍能正常工作（push 后 @ 还能回复）
4. 新功能的使用说明 + 设计思路（不超过 1 页）

## 方向二：Agent 应用开发

运用课程所学的 Agent 核心能力（LLM + 工具 + 循环 + 记忆 + Skills），**开发一个解决真实问题的 Agent 应用**。

### 核心要求

1. 是一个**可以跑起来、有真实用户交互**的产品（不是 PPT）
2. 至少用到 **3 个核心能力**（Function Calling / Agent Loop / Memory / Skills / NPC 任意 3 个）
3. 有一个**真实使用场景**

### 推荐方向

| 方向 | 示例场景 | 核心能力 |
|------|---------|---------|
| 运维助手 | 监控告警自动排查 + 执行修复 + 回复工单 | NPC 触发 + bash 工具 + Agent Loop |
| 代码审查 Bot | PR 提交后自动 review、标注问题、打分 | NPC + read/grep + Skills（团队规范） |
| 学习助手 | 把论文/文档拆成 Q&A 闪卡，记住学习进度 | LLM + 工具（read/write）+ Memory |
| 项目脚手架 Agent | 描述需求后自动生成项目结构、代码模板、配置 | Plan-and-Solve + write + bash |
| 数据分析 Agent | 自然语言提问 → 生成 SQL/Pandas 代码 → 执行 → 可视化 | Agent Loop + bash + Reflection |
| 文档生成器 | 读代码自动生成 API 文档 / CHANGELOG | read + grep + Skills（文档规范） |
| 个人知识库 | 丢链接/笔记进去，自动提炼 + 主题归档 + 检索 | Memory + Skills + 自定义工具 |
| 面试模拟器 | 出题 → 用户作答 → AI 评分 + 追问 | Agent Loop + Reflection + Memory |
| 日报/周报生成 | 读 git log + Issue，自动汇总生成报告 | bash + LLM + 定时触发 |

### 验收标准

1. 评审时现场演示，至少跑通 3 个真实场景
2. 仓库有完整代码 + README + 使用说明
3. README 中标注用到了哪些核心能力
4. 如组队，写清每人贡献

## 方向三：自由 VibeCoding

题材不限，内容不限，完全自由发挥。用 AI 辅助编程（VibeCoding）的方式，**做出一个你想做的东西**。

### 核心要求

1. 是一个**完整可运行**的项目
2. 开发过程中充分利用 AI 辅助（CodeBuddy / NPC / 你自己的 Agent 均可）

### 推荐方向

| 方向 | 示例 | 说明 |
|------|------|------|
| 小游戏 | 贪吃蛇 / 2048 / 打字练习 / 扫雷 | Web 或终端均可，重在完整体验 |
| 效率工具 | Markdown 笔记应用 / Todo + 番茄钟 / 文件批量重命名 | 解决你自己的痛点 |
| 数据可视化 | GitHub 活跃度看板 / 个人记账统计 / 课程知识图谱 | 用 echarts / d3 / matplotlib |
| CLI 工具 | git 工作流封装 / 项目模板生成器 / 批量图片处理 | Python / Node / Go 均可 |
| Web 应用 | 个人博客 / 简历网站 / 在线白板 | 前后端分离或全栈 |
| 创意项目 | AI 生成诗词配画 / 音乐可视化 / 像素画编辑器 | 发挥想象力，不设限 |
| 硬核挑战 | 实现一个简易编译器 / 数据库 / HTTP 服务器 | 适合有追求的同学 |

### 验收标准

README 含：项目说明 + 运行方式 + 截图

## 评分标准（满分 30 分）

| 维度 | 分值 | 说明 |
|------|------|------|
| **功能完整性** | 10 分 | 方向一：2 个功能跑通；方向二：3 个场景跑通；方向三：项目完整可运行 |
| **代码质量** | 8 分 | 模块清晰 / 错误处理 / 接口设计合理 |
| **创意与实用性** | 7 分 | 选题合理性 + 创新度 + 实际价值 |
| **文档与演示** | 5 分 | README + 截图/录屏 + 设计说明 |
